SOS.Ajuda — Mega Update
=========================

Protótipo front-end para apresentação.

Arquivos:
- index.html
- styles.css
- script.js

Como usar:
1. Extraia o ZIP.
2. Abra index.html no navegador.

Recursos:
- Tema claro/escuro com persistência.
- Layout responsivo.
- Busca e filtros de pedidos.
- Criação de pedidos em modal.
- Pedidos criados aparecem na tela e ficam salvos no navegador.
- Botão de localização demonstrativo usando a API de geolocalização.
- Navegação, toast, cards e estados vazios.
- Sem sistema de login, cadastro ou backend.

Observação:
Este projeto é um protótipo navegável. Os dados são locais ao navegador e não são enviados para um servidor.
